# GameZoneRental

 Identitas Proyek
- Institusi: Universitas Muhammadiyah Tasikmalaya
- Program Studi: Pendidikan Teknologi Informasi
- Mata Kuliah: Pemrograman Java Dasar
- Nama Proyek: GameZone Rental PS

 Deskripsi
GameZone Rental PS merupakan aplikasi berbasis Java Console
untuk menghitung biaya penyewaan PlayStation 4 dan PlayStation 5.
Program menyediakan perhitungan biaya sewa, diskon 10% untuk
durasi minimal 3 jam, pilihan tambahan minuman, pencetakan struk,
serta fitur transaksi berulang.

 Fitur
- Input nama pelanggan
- Pilihan PlayStation 4 dan PlayStation 5
- Input durasi bermain dalam jam
- Diskon 10% untuk durasi minimal 3 jam
- Pilihan minuman seharga Rp5.000
- Perhitungan total pembayaran
- Tampilan struk transaksi
- Transaksi berulang

 Teknologi
- Bahasa pemrograman: Java
- IDE: Apache NetBeans
- Input: Scanner
- Percabangan: if-else
- Perulangan: while dan do-while
- Method: bacaAngka() dan cetakStruk()

 Cara Menjalankan
1. Buka Apache NetBeans IDE.
2. Buka proyek GameZoneRentalPS.
3. Pastikan JDK sudah dikonfigurasi.
4. Jalankan proyek melalui Run Project.
5. Masukkan data pelanggan sesuai petunjuk di console.
